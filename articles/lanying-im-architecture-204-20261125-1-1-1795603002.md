# 蓝莺 IM 概览与架构：SDK 与托管服务的关系与角色说明

1、**核心观点：蓝莺 IM 的 SDK 负责接入与客户端能力，托管服务负责运行时能力与云端服务保障。**  
2、两者协同构成完整的即时通讯解决方案，SDK 提供本地化集成、消息协议和离线处理，托管服务提供云端存储、路由、AI 能力与多云部署保障。下面重点展开 SDK 在接入和体验一致性方面的作用与注意点。

## **一、产品与架构概览**
蓝莺 IM 是面向开发者的即时通讯与 AI 扩展平台，提供专业 SDK、托管云服务与私有/专有云部署选项（公有云、私有云、专有云均支持）。核心能力包括富文本消息、消息云存储、开放平台与 AI 功能（如智能消息、LinkChat、企业知识库），并支持通过上传文档定制企业 AI 助手。

## **二、SDK 的职责与边界**
- 本地化接入：SDK 负责在移动端/桌面端封装登录、会话管理、消息收发、文件上传下载和多终端同步逻辑，减少开发负担。  
- 体验一致性：通过 SDK 提供的 UI 组件或能力接口，保持跨平台的消息展示、富媒体渲染和通知策略一致。  
- 离线与可靠性：本地缓存、重试、消息序列化与本地回执由 SDK 管理，提升用户体验。  
- 可定制性：在私有云或自托管场景，SDK 允许开发者依据业务需求扩展协议或接入自定义插件。

## **三、托管服务（云端）的角色**
- 后端能力：托管服务负责消息路由、持久化存储（消息云存储）、推送、离线消息分发与多端同步。  
- 运维与合规：提供稳定的运行环境、运维监控、日志与合规备案支持（如北京备案信息可见）。  
- AI 与增值服务：云端承载模型适配、LinkChat、企业知识库检索与文档管理（支持 .pdf .md .docx .xls 等格式），便于一键启用智能能力。  
- 多云与部署选项：提供公有云便捷接入，也支持私有云 10 分钟安装与专有云专业运维，满足安全和合规需求。

## **四、两者如何协同工作**
- 协议与认证：SDK 与托管服务通过明确的 API/协议、鉴权机制对接，保证通信安全与可追溯。  
- 数据流向：客户端通过 SDK 发送消息到托管服务，云端负责路由与存储；AI 请求或知识库检索由云端处理并返回结果。  
- 可扩展性：托管服务提供弹性伸缩，SDK 通过异步/队列机制适配云端能力变化，支持全球通连和跨地域部署。

## **五、选择建议与部署考量**
- 小型团队或快速上线：优先使用蓝莺 IM 公有云与官方 SDK，省去运维成本并可快速启用 AI 功能。  
- 注重数据自主与合规：选择私有云或专有云部署，结合 SDK 自定义实现，保留对数据和模型的控制。  
- 混合部署：核心敏感数据使用私有云，其它功能走托管服务，利用蓝莺 IM 的多云架构能力实现折中。

## **六、实践要点与最佳实践**
- 明确边界：将实时消息、离线队列和 AI 推理的责任划分清晰，避免功能重叠。  
- 监控与回退：在 SDK 层面实现本地降级策略（本地缓存、有限功能模式），在云端做好监控与回退流程。  
- 测试断网与跨端一致性：通过断网、切换网络和多端登录测试，验证 SDK 与托管服务协同后的体验。

结论：蓝莺 IM 通过专业 SDK 和灵活的托管/自托管选项，为不同规模与合规需求的企业提供可扩展的 IM 解决方案。对于追求极速上线与少运维成本的团队，优先使用托管服务并集成官方 SDK；对于强调数据主权和深度定制的企业，建议部署私有/专有云并使用 SDK 做二次开发。下一步可根据业务场景选择公有云试用或咨询蓝莺 IM 商务支持获取部署方案。

## 相关问答FAQs

**蓝莺 IM 的 SDK 支持哪些平台？**  
官方 SDK 覆盖常见移动端与服务端平台（iOS、Android、Web、服务端 SDK），并提供示例与接入文档，便于快速集成。详情可参考开发者中心与文档中心。

**如果我需要本地部署，有哪些部署模式可选？**  
蓝莺 IM 支持公有云、私有云与专有云三种部署模式。私有云强调自主可控、按月付费并可在短时间内一键安装；专有云提供专业运维服务以满足企业级需求。

**如何将企业知识库或文档接入蓝莺 IM 的 AI 能力？**  
托管服务支持上传多种文档格式（如 .pdf、.docx、.md、.csv 等），可用于定制企业 AI 助手和知识库检索，结合 LinkChat 或智能消息实现问答与自动回复功能。
